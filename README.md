# Setup and Execution Guide

## Clone the Repository

```powershell
git clone https://github.com/chainchair/AutoScalingService.git
```
```
cd <repository_folder>
```

---

## Create a Python Virtual Environment

```powershell
python -m venv .venv
```

Activate the virtual environment:

```powershell
.venv\Scripts\activate
```

---

## Install Dependencies

```powershell
pip install -r requirements.txt
```

---

## Generate gRPC Files

The gRPC Python files must be generated from `metrics.proto`.

Run the following command in PowerShell:

```powershell 1
python -m grpc_tools.protoc -I. --python_out=. --grpc_python_out=. metrics.proto
```
```powershell 2
python -m grpc_tools.protoc -I. --python_out=. --grpc_python_out=. monitor.proto
```
This generates:

* `metrics_pb2.py`
* `metrics_pb2_grpc.py`

* `monitor_pb2_grpc.py`
* `monitor_pb2_grpc.py`


These files are autogenerated and should not be edited manually.

---

## Running the Application

### Start AppInstance

```powershell
python appInstance.py
```

---

### Start MonitorC

```powershell
python monitorC.py
```

The gRPC server should start on port `50051`.

### Start MonitorS

```powershell
python MonitorS.py
```

The gRPC server should start on port `50051`.

### Start ControllerASG

```powershell
python ControllerASG.py
```

---

### If needed to reload grpc proto files use these command
```
- python -m grpc_tools.protoc -I. --python_out=. --grpc_python_out=. metrics.proto
- python -m grpc_tools.protoc -I. --python_out=. --grpc_python_out=. monitor.proto
```
## About Pylance Warnings

You may see warnings such as:

```text

```
